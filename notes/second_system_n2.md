# 第二个体系：N₂ / STO-3G

写于 2026-11-18。目的：检验 Schur 证书与水体系的结果是不是"那一个矩阵的性质"。

## 为什么选 N₂

水/STO-3G 只有 441 个行列式，是孤立一例。N₂/STO-3G 有 **14400 个**（33 倍），
成键性质不同（三键而非孤对），并且对角间隙更小。若块路线在这里也同样失效、
Schur 路线也同样有效，那至少是现象而不是轶事。

## 计算约定

- 几何：`N 0 0 0; N 0 0 1.0977` Å（实验平衡键长）
- 基组：STO-3G，全电子，S_z = 0 扇区，14400 个行列式
- E_FCI 由 ARPACK 求最低三个本征值，并与 pyscf `fci.FCI` 交叉验证：
  差 **2.1e−12 Ha**
- 脚本：`experiments/complement/n2_certificate.py`
- 数据：`experiments/complement/certificate_n2.json`、`.log`

## 结论（必须如实表述）

1. **块路线在两个体系上都彻底失效**（1241 与 3451 kcal/mol），这不是水矩阵的偶然。
   原因一致：τ/Δ 分别为 4.5 与 17.8，远大于 1。
2. **Schur 路线在两个体系上都带来两到三个数量级的改进**（1443× 与 344×），
   机制一致：只需参考行 + 一次线性求解，不需要谱范数。
3. **但 Schur 的绝对误差不随规模保持**：从 0.86 kcal/mol 退化到 10.03 kcal/mol。
   所以**不能**宣称"该证书给出 kcal 级精度"。诚实说法是：
   > 在 441 行列式上得到亚 kcal 的严格下界；在 14400 行列式上严格性保持但绝对
   > 松弛增大到约 10 kcal/mol，与 τ/Δ 的增大同时发生。
4. δ 从 7.4e−4 降到 4.2e−6（小 176 倍），是松弛退化的直接来源：
   `bᵀA⁻¹b` 的误差半径正比于 1/δ。
