# 严格陈述：单参考 Schur 界

日期 2026-11-13。体系水分子 / STO-3G，441 个行列式。所有数值由
`experiments/complement/schur_route.py` 与下述推导脚本实际算出，FCI 矩阵经
`fci.FCI` 校验（差 1.4e-12 Ha）。

## 设定

按参考行列式分块：

    H = [[ d,   bᵀ ],
         [ b,   H_r ]]        (n×n, H_r 是 (n−1)×(n−1))

其中 `d = ⟨ref|H|ref⟩`，`b` 是耦合列。

## 定理（Schur 界）

设实对称 H，`d = H₀₀`，`H_r` 是删去第 0 行/列的子矩阵，`bᵀ = H₀,₁..ₙ₋₁`。
定义

    g(λ) := d − bᵀ (H_r − λI)⁻¹ b,      λ < λ_min(H_r).

若 `λ₁ < μ < λ_min(H_r)`，则 `g(μ) ≤ λ₁`。

### 证明

**第一步（特征多项式恒等式）。** 对 λ < λ_min(H_r)，矩阵 `H_r − λI` 正定可逆，
于是分块行列式恒等式给出

    det(H − λI) = (d − λ)·det(H_r − λI) − bᵀ adj(H_r − λI) b

其中 `adj(M) = det(M)·M⁻¹`。两边除以 `(d−λ)·det(H_r − λI)`：

    det(H − λI) / [(d−λ) det(H_r − λI)] = 1 − bᵀ(H_r − λI)⁻¹b / (d − λ)

注意 `bᵀ(H_r − λI)⁻¹b / (d − λ) = [d − g(λ)] / (d − λ)`，因此

    det(H − λI) / [(d−λ) det(H_r − λI)] = 1 − (d − g(λ))/(d − λ)
                                        = (g(λ) − λ)/(d − λ).

**第二步（符号）。** 由于 λ < λ_min(H_r)，`det(H_r − λI) > 0`。

**第三步（区间内无本征值）。** 设 `λ₁ < μ < λ_min(H_r)`。任取 λ ∈ (λ₁, μ)：
此时 λ 不是 H 的本征值，故 `det(H − λI)` 的符号恒定于 (λ₁, μ) 上。当 λ → λ₁⁺ 时，
因 λ₁ 是单本征值，`det(H − λI)` 的一阶行为使 λ 恰在 λ₁ 处变号，所以在 (λ₁, μ) 上
`det(H − λI)` 与 `λ − λ₁` 同号，即 `det(H − λI) > 0`。代入第一步：

    (g(λ) − λ)/(d − λ) > 0  对一切 λ ∈ (λ₁, μ).

**第四步（关键假设 `d > λ₁`）。** 由 Rayleigh–Ritz，`λ₁ ≤ ⟨ref|H|ref⟩ = d`；
分离性假设下 `λ₁ < d`，故 `d − λ > 0`，于是 `g(λ) > λ` 对一切 λ ∈ (λ₁, μ)。

**第五步（单调性）。** `d/dλ[(H_r − λI)⁻¹] = (H_r − λI)⁻² ⪰ 0`，即逆关于 λ
单调不减（逐元意义上由正定性给出 `(H_r−λI)⁻¹` 关于 λ 递增）。故 `g` 递减。
由 μ 与 λ ∈ (λ₁, μ) 的关系 λ < μ 得 `g(μ) ≤ g(λ)`。结合第四步 `g(λ) > λ`，
只需 λ → λ₁⁺ 时 `g(λ) → g(λ₁)` 且 `g(λ₁) ≥ λ₁`。

**结论。** 若 `g(λ₁) ≥ λ₁`，则对一切 λ ∈ (λ₁, μ) 有 `g(μ) ≤ g(λ)`；取 λ ↓ λ₁ 得
`g(μ) ≤ λ₁`。∎

### 诚实标注

- 第一步至第三步是**严格**的。
- 第四步用了**分离性**（`λ₁ < d`），这是对参考态的非退化假设，不是自动成立。
  对 RHF 基态通常成立，但需要单独论证。
- 第五步到结论之间的连续性论证，我给出了 `g(λ₁) ≥ λ₁` 这个**额外假设**。
  若该假设不成立（即 `g(λ₁) < λ₁`），则由 `g` 递减知 λ₁ 不是 `g` 的不动点，
  而不动点方程 `λ = g(λ)` 至多一个解，故此时 λ₁ 不会被复现，结论需重新论证。
  **我没有证明 `g(λ₁) ≥ λ₁`。** 数值上 `g` 的不动点精确等于 λ₁，这恰恰说明
  `g(λ₁) = λ₁`，即该假设在数值上取等号——这是边界情形，需要更细致的论证
  （例如证明 λ₁ 是 g 的不动点，而这由第一步的恒等式在 λ = λ₁ 处直接给出）。

## 仍未解决的：d < λ_min(H_r) 的认证

这是本路线唯一的额外要求。实测 Gershgorin 无法认证它：

| 方法 | (H_r − dI) 的下界 |
|---|---|
| Gershgorin（行和） | −1.0207 |
| 加权（1/行和） | −0.7075 |
| 加权（指数） | −0.9594 |

全部为负，即无法认证正定性。原因清楚：`H_r − dI` 的物理含义是关联能间隙
(0.447 Ha)，而最紧一行的耦合绝对值和是 1.380 Ha，绝对值型界在这里按定义就过松。

440 行中 389 行满足对角占优，51 行不满足——失败是局部的，不是全局的。
这提示：可能可以只对不满足的那些行做更精细的处理（例如把它们的耦合行
投影到已知的低维子空间），我没有做这件事。

## 结论

**Schur 界是本研究第一个在化学精度量级上的可认证下界候选**（0.86 kcal/mol），
代价是两条额外假设：分离性 `λ₁ < d`（对 RHF 基态合理）与 `d < λ_min(H_r)`
（Gershgorin 认证失败，尚需其他途径）。

定理的完整证明中，第 1–3 步严格，第 5 步到结论之间的连续性论证依赖
`g(λ₁) ≥ λ₁`，我未证明，仅知数值上取等号。**因此现在还不能称其为已证明的定理。**
