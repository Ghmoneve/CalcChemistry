# 已认证的 Schur 下界：水分子 / STO-3G

日期 2026-11-13。所有数字由 `experiments/complement/verified_cholesky.py` 实算，
输出存档于 `experiments/complement/verified_cholesky.json`。

## 结论

**λ₁ ≥ −75.01338150 Ha，相对 E_FCI = −75.01201163 Ha 的松弛为 0.860 kcal/mol。
这是严格下界，不是数值候选。**

与此前对比：

| 证书 | 下界 | 松弛 |
|---|---|---|
| 块证书 `d − ‖O‖₂` | −76.989165 | −1241 kcal/mol |
| 块证书（单侧常数） | −76.712979 | −1133 kcal/mol |
| **Schur + 验证式 Cholesky** | **−75.01338150** | **−0.860 kcal/mol** |

改进 1443 倍，且 0.86 kcal/mol 已在化学精度量级。

## 为什么 Gershgorin 必然失败

块证书需要 `A = Hr − dI ≻ 0`。Gershgorin 判定的是对角占优，这是**充分**条件。
本例中 A 的最小对角元是关联能间隙 0.447 Ha，而最紧行的耦合绝对值和是 1.380 Ha。
所以**无论怎么分组、怎么加权，对角占优都不可能成立**。这不是矩阵的问题，是判据的
问题。440 行中 389 行占优、51 行不占优，失败是结构性的。

## 实际使用的判据：验证式 Cholesky

设 `L` 是浮点 Cholesky 因子。对任意对称 `A` 与 `L`，

    A = L Lᵀ + E,      ‖E‖₂ ≤ ‖E‖_F ≤ ε,

由 Weyl 不等式

    λ_min(A) ≥ λ_min(L Lᵀ) − ε = σ_min(L)² − ε,

而 `σ_min(L) = 1/‖L⁻¹‖₂ ≥ 1/(√n ‖L⁻¹‖_∞)`。所以只要
`1/(n ‖L⁻¹‖_∞²) − ε > 0` 就证明了 `A ≻ 0`。全程只需要**两次三角求解加一个残差**，
不做任何本征值计算。

误差项：

    ε = ‖A − fl(LLᵀ)‖_F + n·u·‖|L||L|ᵀ‖_F/(1−n·u),    u = 2⁻⁵³.

### 实测

| 量 | 值 |
|---|---|
| ‖A − fl(LLᵀ)‖_F | 5.185e-14 |
| 舍入误差界 | 1.973e-11 |
| ‖L⁻¹‖_∞ | 1.749 |
| σ_min(L) 下界 | 2.725e-02 |
| **认证 λ_min(A) ≥** | **7.427e-04 > 0** |
| 真值 λ_min(A) | 0.349986 |

认证下界比真值松 471 倍，但**严格为正**，足以成立。这里余量极大：即使
`‖L⁻¹‖_∞` 有 100% 的相对误差也仍然通过。

## bᵀA⁻¹b 的严格区间

有认证的 `λ_min(A) ≥ δ > 0` 后，任取一个近似解 `ŷ`（残差 `r = b − Aŷ`），
因 `y − ŷ = A⁻¹r`，

    bᵀA⁻¹b = bᵀŷ + bᵀA⁻¹r,     |bᵀA⁻¹r| ≤ ‖b‖‖r‖/δ.

实测 `‖b‖ = 0.317864`，`‖r‖ ≈ 4e-12`，`δ = 7.427e-04`：

    bᵀA⁻¹b = 5.067489e-02 ± 1.824e-12.

于是 λ₁ ≥ d − 5.067489e-02 = −75.01338150 Ha。

## 这个证书的代价边界：必须说清楚

**它是严格的，但不省算力。** Cholesky 需要完整的 440×440 矩阵 A，复杂度 O(n³/3)；
相比完全对角化是 O(n³) 但常数小得多，且不需要本征向量。**渐进阶相同。**

因此这个结果的意义不在复杂度，而在：

1. 把一个**不可用**的证书（1241 kcal/mol）换成一个**可用**的（0.86 kcal/mol）；
2. 把「需要什么」说清楚了：不是 τ，而是 `λ_min(A)` 的正性与一个标量 `bᵀA⁻¹b`；
3. 认证手段（验证式 Cholesky + 残差界）是标准的、可自动化的，不依赖任何未证命题。

**它没有解决指数墙。** 要真正省算力，必须在不构造 A 的前提下界定这两个量。

## 下一层：真正的规模化问题

`bᵀA⁻¹b` 是形如 `bᵀf(A)b` 的二次型，经典做法是 Lanczos 三对角化 + Gauss 求积
（Golub–Meurant）。若能同时给出：
- 一个严格的 `λ_min(A)` 下界（Gauss–Radau 需要固定节点在谱下方），
- 以及 `bᵀA⁻¹b` 的上界（Gauss–Radau 对 1/t 这类函数给上界），

就能在 O(k·nnz) 内完成，k 是三对角化的步数。**但严格的 `λ_min` 下界仍是同一个
问题的下一层**：Gershgorin 给的 −1.02 不可用。可行方向是用 Lanczos 的
Ritz 值加 Kato–Temple 型 a posteriori 界自举，我没有做。

**结论：今天拿到的是「严格但不可扩展」的证书。可扩展版本仍是开放问题。**

## 附：廉价判据全部失败的实测（同日）

在找到验证式 Cholesky 之前，系统测试了所有"局部/廉价"的正定判据。全部失败，
且失败幅度是 2–5 倍，不是临界情形。

| 判据 | 得到的 λ_min(A) 下界 |
|---|---|
| Gershgorin（自然序） | −1.020686 |
| Gershgorin（对角升序） | −1.020686 |
| Gershgorin（对角降序） | −1.020686 |
| Gershgorin（行和/对角升序） | −1.020686 |
| 最优对角加权 Gershgorin | −0.707469 |
| 真值 | **+0.349986** |

**一个自我纠正：** 我曾以为 Gershgorin 是置换相关的、可以靠重排救回来。这是错的。
Gershgorin 的界 `min_i (A_ii − Σ_{j≠i}|A_ij|)` 是逐行的量，重排只是重新标号，
界不变。实测四种排序给出完全相同的 −1.020686。

块对角占优也失败，且失败随分块变细而加重：

| 块大小 | 块数 | 块内最小 λ_min | 块外 ‖·‖₂ | 认证 |
|---|---|---|---|---|
| 220 | 2 | 0.360565 | 0.903460 | 否 |
| 110 | 4 | 0.382475 | 1.265005 | 否 |
| 55 | 8 | 0.385686 | 1.426676 | 否 |
| 22 | 20 | 0.406437 | 1.505341 | 否 |
| 10 | 44 | 0.413487 | 1.830804 | 否 |

块内间隙始终 0.36–0.41，块外耦合范数 0.90–1.83，**后者始终大 2–5 倍**。

### 结论

这个矩阵在行列式基下**没有局部结构**：耦合是长程的，分块越细越糟。所以
没有任何基于"局部性"或"对角占优"的判据能认证它——这与 FCI 矩阵的 QMA-困难性
是相容的。

**只有分解类方法（Cholesky）可行，代价 O(n³)。** 这是本项目目前最诚实的分界线：
严格性可以买到，但要用和完全对角化同阶的算力买。
