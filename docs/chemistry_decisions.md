# 化学体系决策记录

记录用户确认的体系选择与文献依据。凡标 **已核验** 的条目，DOI 均经 Crossref
回读（`scripts/verify_references.py` 同一流程）。未核验者明确标注。

## 1. 用户确认的体系

| 项 | 用户陈述 |
|---|---|
| 目标材料 | CaF₂ 晶体沉积；另有 Al₂O₃/MoCl₄ |
| 衬底（实验） | Si(100) |
| 实际生长面 | 在已有 CaF₂ 表面继续生长 |
| Al₂O₃ 取向 | γ-Al₂O₃(100) 或 (110)，尚未定 |
| Ca 前驱体 | 未定，用户提问「不应该是含 F 的吗」 |

关键推论：既然实际生长发生在 CaF₂ 表面，**化学上相关的表面是 CaF₂，不是
Si(100)**。Si(100) 只决定晶体取向关系（CaF₂/Si 外延），不参与后续的表面
半反应。因此第一性原理建模应以 CaF₂ 表面为对象。

CaF₂ 天然解理面为 (111)，由 F⁻—Ca²⁺—F⁻ 三层构成，层间距 3.14 Å，**F 终止**。
来源：US11111578B1 专利文本对该结构的描述。

## 2. 「Ca 前驱体是否应该含 F」

**主流热 ALD 中：不含 F。** 理由不是设计偏好，而是挥发性约束。金属氟化物
ALD 的根本困难是缺少好的挥发性氟源：Ca–F 键极强，CaF₂ 熔点约 1418 °C，
不可能作为可输送的前驱体。因此标准架构是两个独立脉冲：

    脉冲 A：挥发性、无 F 的 Ca 有机前驱体（沉积 Ca）
    吹扫
    脉冲 B：独立氟化剂（提供 F）
    吹扫

已报道的 CaF₂ ALD 体系（全部为「无 F 的 Ca 前驱体 + 独立氟源」）：

1. **Ca(thd)₂ + NH₄F**（NH₄F 在 260–400 °C 原位分解为 NH₃ + HF）——
   最早的 CaF₂ ALD。J. Electrochem. Soc.，DOI `10.1149/1.2054910`（未回读核验）。
   thd = 2,2,6,6-四甲基-3,5-庚二酮。

2. **Ca(thd)₂ + TiF₄**，300–450 °C，生长率 1.6 Å/cycle，比前法高 4 倍。
   净反应（原文式 1）：

       2 Ca(thd)₂(g) + TiF₄(g) → 2 CaF₂(s) + Ti(thd)₄(g)

   **已核验**：Pilvi, Arstila, Leskelä, Ritala, *Chem. Mater.* **19**, 3387–3392
   (2007), DOI `10.1021/cm0629412`。
   另有 **已核验**：Pilvi, Ritala, Leskelä, Bischoff, Kaiser, *Appl. Opt.* **47**,
   C271 (2008), DOI `10.1364/AO.47.00C271`。

3. **HF–pyridine 作为氟源**，用于 ZrF₄/MnF₂/HfF₄/MgF₂/ZnF₂ 等；QCM 显示
   ZrF₄、HfF₄ 表面在 HF 脉冲后吸附约 2 个 HF 作为「氟储库」。
   **已核验**：Lee, Sun, Young, George, *Chem. Mater.* **28**, 2022–2032 (2016),
   DOI `10.1021/acs.chemmater.5b04360`。

4. **酰胺盐（amidinate）路线**：双(N,N-二异丙基甲脒基)钙(II)二聚体
   `[Ca(amd)₂]₂` + 无水 HF，175–250 °C，0.3–0.4 Å/cycle。
   J. Vac. Sci. Technol. A **41**, 042405 (2023)（未回读核验）。
   专利 US11111578B1 给出更宽的第二前驱体选择：HF、HF-Py、WF₆、TaF₅、
   MoF₆、NbF₅，并称可在 200 °C 以下工作。

**用户的直觉在特定一类里是对的：含 F 的 Ca 前驱体确实存在。** 即**氟化
β-二酮盐**，被文献明确定义为「single-source precursor」，同时供应金属离子
与氟组分：

- `Ca(hfa)₂·glyme`（hfa = 六氟乙酰丙酮），hfa 的 CF₃ 基团提供 F。
  **已核验**：Lo Presti, Pellegrino, Malandrino, *Dalton Trans.* **51**,
  7352–7362 (2022), DOI `10.1039/d2dt00479h`。原文明确称此类加合物
  "represent a single-source precursor for both the alkaline-earth ion and
  the fluorine component"，并演示了 AP-MOCVD 生长 MgF₂/CaF₂。
- `Ca(DFHD)₂·H₂O`（DFHD = 十氟庚二酮）在 Si 上给出 (111) 取向 CaF₂ 薄膜
  （MOCVD，未回读核验）。

代价：单源路线要求活化 C–F 键，因此需要更高温度，且碳残留风险更大。
它主要在 MOCVD / 空间 ALD 中被验证，**不是主流热 ALD 路线**。

## 3. γ-Al₂O₃ 晶面选择

推荐 **(110)** 而非 (100)，三条独立理由：

1. **面积占比**：(110) 约占 γ-Al₂O₃ 总表面的 70–83%（ScienceDirect
   S0022113921001184 引言，未回读核验）。
2. **羟基状态**：(100) 在典型预处理条件下**已脱羟基**；ALD 的 MoCl₄ 半反应
   需要表面 OH，因此 (100) 不合适。来源：*ACS Catal.* 羟基 NMR+DFT 研究
   （DOI `10.1021/acscatal.3c00495`，未回读核验）。
3. **直接相关文献**：已有 γ-Al₂O₃(110) 上 H₂O **与 HF** 的吸附及过渡态
   DFT 计算，共 17 个 H₂O 构型、19 个 HF 构型，并给出 OH/HF 共吸附最稳定
   构型（覆盖度约 0.55/0.40，吸附能 −2.97 eV）。这对 CaF₂ 涉及的 F 化学
   直接可比。

另有 γ-Al₂O₃(100)/(110) 上 CO₂ 吸附的 DFT 板模型数据（*Langmuir*,
DOI `10.1021/la802295x`，未回读核验）可用于交叉核对表面位点标注：
(110) 暴露 3 配位 Al、4 配位 Al、2 配位 O、3 配位 O；(100) 暴露 5 配位 Al、
3 配位 O、4 配位 O。

## 4. 关于「Al₂O₃/MoCl₄」的一处事实更正

**MoCl₄ 本身几乎没有 ALD 文献。** 检索到的钼氯化物 ALD 工作使用的是：

- `MoOCl₄`（氧氯化物）——面积选择性 ALD 生长 MoOₓ，*J. Vac. Sci. Technol. A*
  **38**, 042406 (2020)；200–300 °C
- `MoCl₅` / `MoCl₆`——Mo 金属沉积专利
- `MoO₂(thd)₂` + O₃——晶态 MoOₓ
- `Mo(NMe₂)₄` + O₂/O₃——MoO₂

若目标确实是 MoCl₄，需要确认它是实验实际使用的试剂，还是 MoOCl₄ / MoCl₅
的笔误。这一点会改变整个半反应化学计量，必须在建模前定清。

## 5. 建议的首个算例

**`[Ca(amd)₂]₂` + HF 在 CaF₂(111) 表面。**

理由：
- 温度最低（175–250 °C），副反应最少，热分解干扰最小
- 半反应干净：`Ca(amd)₂ + 2 HF → CaF₂ + 2 Hamd`（质子化 + 配体交换）
- amidinate 配体原子数少于 thd（C₁₁H₁₉O₂），活性空间更易控制
- 与用户实际「在 CaF₂ 表面继续生长」的场景直接对应

备选：`Ca(thd)₂ + TiF₄`，生长率最高且历史文献最全，但需额外论证 Ti 不掺入
薄膜，且 thd 配体更大。
